# Pub KARA 30 s : « Trois gouttes »

- `kara-pub-30s.mp4` : film produit 30 s, format vertical 9:16, 1080×1920, avec son. Fait à partir de la photo produit : cadrage, lumière de l'aube au matin, trois gouttes au son. Aucun texte ajouté.
- `script.md` : script de tournage de la version avec comédienne (vrais cheveux), à confier à un vidéaste.
- `render/render.py` : script qui génère la vidéo (`python3 render/render.py reference-produit.jpg kara-pub-30s.mp4`).
